# 我的课表 · 离线课表助手

> 一个**完全在本地运行**的校园课表 App。不联网、不注册、不上传，装好就能用，断网也能看。

---

## 项目简介

把教务系统导出的课表（PDF）或脚本抓取的 JSON 导入手机，得到一张深色、好看、能按周查看的课表；
需要上课提醒时，一键导出 `.ics` 丢进系统日历即可。

Android 端用系统 WebView 承载，界面基于**单文件 HTML**（CSS/JS/PDF 引擎全部内联），
所以网页版双击即可用，App 版也不需要任何服务器。

---

## 核心特性

### 🔒 极致隐私
- **纯前端、零网络请求**：页面不包含任何 `fetch`/XHR 到外部服务器的代码，课表只存在本机浏览器存储里。
- **不申请存储权限**：导入只用系统文件选择器；导出走系统分享面板。
- **无账号体系**：不需要登录、不采集设备信息、没有埋点。

### 📄 导入灵活
- **PDF 导入**：直接读教务系统导出的课表 PDF（列表版 / 表格版两种排版都支持），自动识别课程、周次、教室、教师。
- **JSON 导入**：兼容配套抓取脚本生成的 `schedule.json`，也支持本 App 的备份文件。
- **手动兜底**：识别有误可逐条微调，也能手动新增课程。

### 📅 一键进系统日历
- 导出标准 **RFC 5545** 的 `.ics`，包含时区与 `VALARM` 提醒（提前 5/10/15/30/60 分钟可选）。
- 导入 iPhone / Android 系统日历后，上课提醒由系统负责，不依赖 App 常驻。

### 🎨 原生手感
- 深色毛玻璃 UI、底部悬浮按钮、周视图窄列左右滑动、日视图纵向时间轴。
- 今日高亮 + 当前时间红线 + 距下课倒计时。
- 支持自定义背景图（自动压缩）、自定义每节课起止时间、多课表管理（不同学期互不干扰）。

## 下载与安装

APK 请到本仓库的 **[Releases](../../releases)** 页面下载最新版本（例如 `我的课表-v3.1.3.apk`）。

安装步骤：

1. 把 APK 传到手机（数据线 / 微信文件传输助手均可）。
2. 点击安装，若提示「禁止安装未知来源应用」，到系统设置里给「文件管理 / 微信」放行即可（这是安卓对非商店安装包的保护，不是安全告警）。
3. 安装完成打开，首次进入是空课表引导页。

**要求**：Android 7.0 及以上（`minSdk 24`）。

---

## 快速上手

1. **导入课表**：右下角 `＋` → 「导入 PDF」选择教务系统导出的课表 PDF（或「导入 JSON」选择脚本生成的 `schedule.json`）→ 核对识别结果 → 确认导入。
2. **看课表**：顶部选周次；点日期条切换到日视图；右下角 `⚙` 里可改背景、作息时间、导出日历。
3. **导出提醒**：`⚙` → 选择「日历提醒提前量」→ 「导出日历 .ics」→ 在系统分享面板里保存到「文件/下载」→ 打开该文件导入日历。

> 如果先建了空课表再导入，课程会**填进当前空表**；当前表已有课程时，会询问「新建 / 覆盖 / 取消」。

---

## 数据与备份

- 所有数据存于本机（`localStorage`），卸载 App 会一并清除。
- 换设备：`⚙` → 「备份数据 JSON」→ 把文件发到新设备 → 「导入 JSON」。
- 想清空重来：`⚙` 最下方「清空本机所有数据」。

## 技术实现（简述）

| 部分 | 方案 |
|---|---|
| 前端 | 单文件 HTML（约 2.1 MB），CSS/JS 内联，无外部依赖 |
| PDF 解析 | pdf.js 内联（含 Worker 的 Blob 化与 25 个中文 CMap 的 Base64 内联），纯本地解析 |
| 原生壳 | Capacitor 6 + Android WebView（`https://localhost`，安全上下文） |
| 导入/导出 | 系统文件选择器、系统分享面板（Filesystem + Share 插件） |
| 日历 | 手写 RFC 5545 生成器（CRLF、75 字节折行、VTIMEZONE、VALARM） |

---

## 已知限制

- PDF 解析针对教务系统常见导出格式做了适配；若换学校或改版，可能需要微调解析规则。
- 网页版直接用 `file://` 双击打开时，导入 PDF 受浏览器安全策略限制；安装 APK 后无此问题。
- 不提供在线同步；多设备请用「备份 JSON」迁移。
